
# Jarvis Image Analyzer

A local AI component for the Jarvis city improvement project.

## Purpose
Analyze road images for visible infrastructure conditions,
including sidewalks, curb cuts, bike lanes, and road signs.

## Tools
- Python
- Ollama
- Llama 3.2 Vision

## Setup
1. Create and activate a Python virtual environment.
2. Install dependencies with `python -m pip install -r requirements.txt`.
3. Ensure Ollama is running and the vision model is installed.
